"pinch": patch

Servers an installed app runs itself, such as Raycast's, now appear under that app automatically instead of asking you to recognize the app. Pinch attributes a server to an app only when the app's executable runs it directly, so servers you start from a terminal or editor stay in Servers. The Recognize app action and the Recognized apps list in Configuration are gone; any other server can still be recognized until it exits.
Servers run by Xcode's `/usr/bin/python3` are now named after Python instead of Xcode.
